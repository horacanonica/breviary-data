# breviary-data

Compiled liturgical **Office data** for the Breviarium PWA
([fssp-breviary-app](https://github.com/horacanonica/fssp-breviary-app)).

Generated by that repo's `scripts/compile-calendars.mjs` from a Divinum Officium
**FSSP–North America** fork. Each file is one liturgical day in the app's JSON
shape; the app fetches them per day over raw HTTPS (no server needed) and the
service worker caches them for offline use.

```
manifest.json                       calendars + the days available
<calendar-slug>/<YYYY-MM-DD>.json    one day's eight Hours (Latin + English)
```

Calendars (Rubrics 1960 family): `sacramento`, `fssp-usa`, `guadalajara`, `fssp`.

Public-domain liturgical text. To extend the range or add calendars, re-run the
compiler against the fork and push again.
